# AI-Driven Operational Systems Portfolio

A cinematic, ultra-modern personal portfolio for a Saudi professional focused on Security Operations, AI Workflows, Infrastructure Coordination, and Digital Systems.

## Stack

- Next.js App Router
- Tailwind CSS
- Framer Motion
- Lucide React icons
- Vercel-ready static optimization

## Local Development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Customize

Update portfolio content in `lib/data.ts`, including project titles, descriptions, tags, contact links, timeline items, and dashboard demo data.

The main experience is composed from reusable sections in `components/site`.
