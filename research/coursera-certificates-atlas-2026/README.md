# Coursera Professional Certificates Atlas — 2026

A colorful, Arabic-language editorial field guide covering **164 catalogued programs**, **39 providers**, and **11 skill pathways**. It maps learning skills to example practical deliverables and possible related career roles.

## Contents
- `index.html`: responsive, single-file web book with locally embedded SVG marks and provider/category information.
- `catalog.json`: underlying structured certificate records.
- `logo-provenance.csv`: original logo-source tracking and publisher index.
- `logo-gallery.html`: reference gallery of source links for brand marks.

## Evidence and limitations
This guide is a **non-exhaustive research snapshot**, not a guaranteed complete list of Coursera's changing live search pages. Some certificates were referenced from an official directory or announcement rather than independently audited course by course; see program-level evidence labels. Jobs are **examples of role alignment**, not guaranteed placement or professional licensure.

The PDF edition is provided separately in the conversation download. Only **18 publisher SVG marks** were preserved as locally embedded assets in the PDF; remaining issuers have name treatments rather than invented marks, with published-logo links in the web version. Brand marks are used only to identify the issuing entities; the guide is **independent and not affiliated with Coursera**.
